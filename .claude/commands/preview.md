Launch the Next.js dev server and open two browser windows for visual testing.

Steps:
1. Start the dev server with `npm run dev` in the background
2. Wait for the server to be ready
3. Open a desktop browser tab (1440x900) at the dev server URL
4. Open a mobile browser tab (390x844, iPhone 14 Pro) at the dev server URL

If the dev server is already running (port 3000 in use), skip starting it and just open the browser tabs pointing to the existing server.
